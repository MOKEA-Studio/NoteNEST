## 19. 실제 UI 관찰

### 환경

- 날짜: 2026-08-10
- 앱: Notion macOS desktop
- 방식: 읽기 전용 UI 탐색

### 확인한 공개 구조

- native tab bar
- workspace switcher
- back/forward/new tab/sidebar toggle
- Home, Chat, Meetings, Inbox, Search
- Recents, Agents, Private, Teamspaces
- Library, My tasks, Marketplace, Notion Calendar, Help, Trash
- page breadcrumb, edited time, Share, Copy link, Favorite, Actions
- page icon, cover, comment, editor
- Meeting note의 Notes, format, Start transcription, consent
- floating AI button

### 개인정보 원칙

- 개인 page title 미기록
- workspace/team name 미기록
- 회의 제목·참석자·내용 미기록
- 메뉴와 레이아웃 패턴만 사용
